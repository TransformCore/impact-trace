# Security Policy

## Supported Versions

ImpactTrace is pre-1.0 and only the latest published release is supported with security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Instead, report it privately using [GitHub's private vulnerability reporting](https://github.com/TransformCore/impact-trace/security/advisories/new) for this repository.

Include as much detail as possible:

- Affected version(s)
- Steps to reproduce
- Potential impact

We aim to acknowledge reports within a few business days.
